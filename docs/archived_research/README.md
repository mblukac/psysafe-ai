# Retired pre-0.2 notes

The research and implementation notes previously stored here described the retired pre-0.2 API. They mixed open-ended model reasoning, confidence and severity fields, person-level or clinical framing, numerical boundaries, and product claims that the current package does not support.

They have been removed from current documentation to avoid presenting historical ideas as deployment guidance. Git history preserves them for project archaeology. Current rationale and sources live in [design principles](../design_principles.md); current classifier scope lives in [classifier reference](../classifiers.md).
